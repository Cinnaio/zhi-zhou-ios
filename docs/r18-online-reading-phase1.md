# 在线 R18 阅读第一版

本轮支持受授权的在线阅读；限制级作品暂不提供离线下载。入口为「我的 → 内容模式」。默认安全模式；明确确认成年并通过站点 Turnstile 后，由 `/api/content-policy/unlock` 授予当前 Bearer 会话访问权。

## 会话与阅读

- 内容模式保存在独立的 `ContentAccessStore`，不从本地阅读偏好或其他设备的账号偏好授予权限。
- 启动和新登录默认安全模式；应用进程内回到前台时，先复核已有授权再恢复成人模式。
- 前台按最多 60 秒间隔复核；本地授权期限到达、服务端拒绝、策略不可达或站点关闭时回到安全模式。
- 进入后台先移除成人模式页面。模式切换和账号切换重新创建主导航，避免旧列表和受限正文继续展示。
- 请求结果校验内容模式版本和登录 token；账号或模式发生变化后，丢弃旧响应。
- 显式关闭先立即收回本机展示，再调用服务端 `/lock`；网络失败保留提示与重试撤销入口。
- 普通阅读设置上传不携带 `contentMode`，避免字号等修改意外撤销授权。

## 离线边界

- 成人模式的目录和正文通过 Bearer 在线读取，不写入章节内存/磁盘缓存，也不从章节缓存离线回退。
- 成人模式不执行下一章的磁盘预取；阅读状态显示「仅在线」。
- 已知限制级作品禁用详情下载入口，下载服务本身也拒绝单章和批量保存。
- 离线下载继续使用 `contentMode=safe`。服务端目录/正文明确拒绝 safe 模式的限制级请求，即使携带管理员或已授权读者凭证。
- 原生 API 会话不接收或发送 Cookie，以免网页成人访问 Cookie 混入匿名的安全下载路径。
- 普通作品的安全模式下载、磁盘缓存和离线阅读继续保留。封面仍沿用现有图片缓存策略，本轮的离线限制针对章节正文。

## 服务端配套

Web/API 仓库同时新增 `/api/content-policy/native-challenge`，使用真实站点来源加载 Turnstile。页面只公开 Site Key，不接收登录 token，不授予访问权限；验证 token 经原生请求交给现有 `/unlock` 服务端校验。

WebView 使用临时存储。原生桥仅接受站点验证页面主 frame 的消息；主 frame 不能导航到其他页面，验证 iframe 仅允许站点验证页及 Cloudflare 挑战域名。验证页响应不缓存，并设置 CSP 与 noindex。

书架和最近阅读响应补充 `contentRating`，iOS 将其传递到作品和阅读入口。

上线顺序：先部署配套 API，再安装经 macOS 编译验证的新 IPA。旧 API 未部署时，验证页面将不可用；不能将本地源码完成视为线上已开放。

## 验收

| 场景 | 预期 |
| --- | --- |
| 默认、新登录、切换账号 | 安全模式，无旧账号受限正文 |
| 未确认成年、验证失败或过期 | 无法开启，允许重新验证 |
| 普通读者通过验证 | 首页/搜索/分类/书架/详情/目录/正文可在线访问受限作品 |
| 单章及整本下载限制级作品 | UI 和下载服务拒绝；safe 章节接口返回 403 |
| 成人模式断网 | 不从磁盘打开成人模式正文；复核失败回到安全模式 |
| 关闭成人模式、会话过期、站点关闭 | 已加载成人页面退出，重新显示安全内容 |
| 修改字号、主题等阅读设置 | 不撤销成人访问会话 |
| 关闭时网络失败 | 本机已安全，保留服务端撤销重试入口 |
| 普通作品下载和离线阅读 | 保持可用 |

Windows 可运行 API 测试、类型检查和既有 iOS 静态检查。新增核心缓存策略 XCTest 需由 macOS 的 `swift test --package-path ZhiZhouCore` 执行；完整 SwiftUI/WebKit 编译和真实站点 Turnstile 流程需 Xcode/真机验收。

2026-10-03 本地验证：R18 访问、社交、业务闭环、分级相关 4 个测试文件共 43 项通过；API 与 Web 类型检查通过；阅读、阅读设置同步、导航、分级、AI 创作参数、AI 生命周期及图片缓存 7 项静态检查通过。导航检查原有正则没有兼容已有的 `.transition(selectionModeTransition)`，已调整检查表达式，未修改该布局。

API 全量结果为 609 项通过、2 项失败。失败属于未修改的 `source-sync.test.ts`，独立运行也复现「尚未配置 PO18.tw 账号」；该测试直接依赖未修改的书源同步与账号服务，不导入本轮修改的路由。本轮未扩大到书源测试 fixture 修复。
