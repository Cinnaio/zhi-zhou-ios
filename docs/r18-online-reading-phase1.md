# R18 账号同步与阅读缓存

入口为「我的 → 内容模式」。iOS 与 Web 共用远程 `reader_settings.shared.contentMode`。账号已开启 R18、站点开放且登录有效时，新设备直接恢复阅读，无需再次成年确认或 Turnstile；首次开启账号模式仍使用现有确认与验证流程。

## 账号与同步

- `/api/content-policy/status` 的兼容字段 `sessionAuthorized` 表示当前有效登录可沿用账号授权，`expiresIn` 为登录剩余期限；不再要求每个会话的 `adult_access_until`。
- 启动、新登录及切换账号先保持安全模式，服务端确认后恢复。没有持久化本地成人授权，冷启动断网不会直接开启 R18。
- 前台最多每 60 秒同步，并支持手动刷新及回前台复核。同步任务由状态层持有，页面退出或重建不会取消它。
- 请求取消不会显示同步失败，也不会撤销模式。暂时断网保留本次运行内最后确认的状态；登录到期、服务端明确拒绝、远程关闭或站点关闭后切回安全模式。断网期间无法获知其他设备关闭，联网同步后生效。
- inactive/background 暂停同步并遮挡主界面中的受限内容，不更改账号模式；正常同步和模式变动不重建主导航。真正账号边界才重建导航。
- 模式关闭立即隐藏已打开的受限详情、目录及阅读器，列表过滤受限作品。异步结果继续校验模式版本及登录 token。
- 显式关闭先收回本机展示，再调用 `/lock`；失败保留撤销重试入口，禁止从尚未撤销的远程状态重新开启。
- 全站关闭清除账号共享成人模式和旧会话字段，重新开放不会恢复旧授权。普通字号、主题同步不携带 `contentMode`。

## 阅读缓存与下载

- 成人模式目录和正文使用 Bearer 读取，成功后复用现有内存/磁盘缓存。缓存键包含账号及 `contentMode`，不会跨账号或混入 safe 下载路径。
- 已加载章节优先使用内存缓存；网络连接失败可读取同账号、同模式的磁盘缓存。服务端 HTTP 401/403 不回退缓存。
- 仅访问过的章节被缓存。成人模式不执行下一章磁盘预取，不提供限制级单章或整本主动下载，下载服务和 UI 仍拒绝这两类操作。
- 普通作品下载继续请求 `contentMode=safe`；限制级目录/正文在 safe 模式仍返回 403。
- API 封面响应允许 private 客户端缓存，网络请求及条件请求仍先验证账号。iOS API 图片只发送 Bearer，不发送验证 Cookie；解码缓存按账号及尺寸隔离，Cookie 刷新和同账号 token 轮换不会清掉封面。缓存命中直接显示图片，减少占位闪烁。
- 网页验证、正文网络响应及缓存有独立边界；原生 API 不接收或发送 Cookie。退出账号后已有磁盘数据不能通过另一个账号读取，存储管理继续支持清理缓存。

## 验收与部署

| 场景 | 预期 |
| --- | --- |
| Web 已开启，iOS 新设备登录 | 同步后直接开启 R18，无需重复验证 |
| 从未开启的账号 | 成年确认和 Turnstile 成功后开启 |
| 页面退出、同步取消、短暂切后台 | 不报告 CancellationError，不因这些事件撤销模式或重建主界面 |
| 临时断网 | 保留本次运行最后确认状态，已读目录和章节可从缓存回退；未缓存正文仍需联网 |
| 冷启动且断网 | 保持安全模式，联网确认后恢复账号状态 |
| 任一端关闭 | 联网同步后隐藏已打开的受限页面和列表条目，safe 请求不能读取受限缓存 |
| 不同账号带上旧访问 Cookie | 服务端拒绝，缓存不能跨账号读取 |
| 登录到期、账号禁用、站点关闭 | 降回安全模式；站点重新开放不会恢复旧授权 |
| 单章及整本受限作品主动下载 | UI、下载服务拒绝，safe 接口返回 403 |
| 封面缓存命中及账号状态轮询 | 保留已解码封面，不因验证 Cookie 刷新重载 |
