# 第四阶段：稳定性与上线验收清单

本阶段暂时只覆盖客户端稳定性与性能验收、隐私与内容合规安全审查，以及正式上线验收。

## 已落地的工程能力

- 收紧图片 URLCache 上限，封面预取队列改为 O(1) 取队列，减少长时间浏览的内存和存储压力。

## 真机专项

在正式候选包上至少验证以下组合，并记录结果、系统版本、包版本和测试时间：

- iPhone SE/小屏机、标准尺寸 iPhone、Pro Max 大屏机、至少一台 iPad。
- 当前支持的最低 iOS、当前主流 iOS；浅色/深色、横竖屏、动态字体放大、减少动态效果。
- 首次安装、登录恢复、在线阅读、无网阅读、批量下载/删除、章节切换、段评和文字选取。
- 低电量模式、弱网/断网恢复、后台切回、锁屏唤醒、系统内存压力。
- Instruments：Time Profiler、Allocations、Energy Log、File Activity；重点记录首屏、章节切换、翻页、封面滚动和批量下载。

验收基线：无主线程卡顿或明显掉帧；长时间阅读不持续增长；下载失败可重试；缓存清理后离线目录状态一致；耗电与存储占用没有异常回归。

## 隐私与安全

- 补齐公开隐私政策 URL、数据处理主体、联系方式、核心业务数据保存期限及删除/咨询渠道。
- 在 App Store Connect 隐私问卷中与 `PrivacyInfo.xcprivacy`、实际网络请求逐项核对。
- Release 包确认不含 DEBUG 的无效证书信任开关、测试服务器地址、测试账号、密钥或调试日志。
- 确认所有生产请求使用 HTTPS；服务端检查 CORS、认证失效、速率限制、数据库迁移和备份恢复。
- 对小说来源、封面、章节正文、用户生成段评/评论逐项确认授权、投诉处理、成人内容开关和年龄分级策略。
- 对上传头像、封面、AI 输入输出、管理接口复核大小限制、权限校验、日志脱敏和错误信息边界。

## 正式上线验收

- CI：iOS unsigned IPA 构建、服务端 typecheck/lint/test/build 全部通过。
- TestFlight：安装、升级、卸载重装、旧版本数据迁移和登录恢复通过。
- 线上：健康检查、数据库迁移、备份恢复通过。
- 内容：抽样检查发现、搜索、阅读、离线、段评、评论、举报、管理后台和安全模式。
- 发布：准备版本说明、已知问题、回滚包、客服/问题响应负责人和首周每日监控安排。

未完成的真机测量、法律文本、App Store Connect 填报和最终内容授权不能仅靠 CI 代替，必须在发布前由对应负责人签字确认。
